Descripción

Documento de seguimiento del progreso de la tesis doctoral elaborado para el Seminario de Investigación del tercer semestre. El registro documenta los avances realizados entre dos versiones del manuscrito de tesis, generando evidencia visual de los cambios mediante la herramienta latexdiff.

Metodología de documentación

El documento utiliza una plantilla especializada (RegistroDiff) que integra tres componentes principales:

  • Bitácora de commits: Registro tabular de los cambios realizados al manuscrito entre las dos versiones comparadas, con descripción de las modificaciones por capítulo.
  • Autoevaluación por capítulo: Rúbrica de progreso que evalúa el estado de avance de cada sección de la tesis.
  • Evidencia latexdiff: Diferencias coloreadas entre versiones del manuscrito — adiciones en azul, eliminaciones en rojo — generadas automáticamente a partir del historial de git del repositorio de tesis.

Aspectos técnicos

La generación del diff utiliza git archive en lugar de latexdiff-vc para garantizar compatibilidad con Git LFS, evitando que los punteros de archivos grandes interfieran con el proceso de comparación. El flujo completo es reproducible mediante el comando make latexdiff-tesis del repositorio.
